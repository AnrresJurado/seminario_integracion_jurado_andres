## 📌 Descripción del Curso

Este repositorio reúne los ejercicios, talleres y proyectos desarrollados en la materia de **Seminario de Integración**. El objetivo general es afianzar habilidades en el desarrollo de software moderno mediante la integración de arquitecturas robustas en el *backend* y *frontend*, utilizando herramientas y marcos de trabajo de alto rendimiento.

---

## 🛠️ Tecnologías Utilizadas y Conceptos Clave

### 🐍 Python
**Python** es un lenguaje de programación multiparadigma, interpretado y de alto nivel, reconocido por su sintaxis clara y legible. Su ecosistema flexible lo convierte en una opción líder para desarrollo web, análisis de datos, automatización e inteligencia artificial.

### ⚡ uv
**uv** es un administrador de paquetes y entornos virtuales para Python desarrollado en Rust. Destaca por su extrema velocidad (hasta 10-100 veces más rápido que `pip`), sirviendo como reemplazo directo de herramientas como `pip`, `pip-tools` y `virtualenv` en flujos de trabajo modernos.

### 🚀 FastAPI
**FastAPI** es un *framework* web moderno y de alto rendimiento basado en Python para construir APIs RESTful. Utiliza *type hints* estándar de Python, ofrece validación de datos automática a través de **Pydantic** y genera documentación interactiva OpenAPI (Swagger UI) de forma nativa.

### 🟦 TypeScript
**TypeScript** es un superconjunto tipado de JavaScript desarrollado por Microsoft que se compila a JavaScript llano. Añade tipado estático opcional, interfaces y clases avanzadas, lo que facilita la detección temprana de errores y mejora la mantenibilidad en aplicaciones a gran escala.

### 🅰️ Angular
**Angular** es un *framework* de desarrollo *frontend* desarrollado por Google para la creación de aplicaciones web de página única (*Single Page Applications* - SPA). Basado enteramente en TypeScript, proporciona una estructura completa fuera de la caja (componentes, inyección de dependencias, enrutamiento, formularios y servicios).
